# Hornet Silksong Cursor for macOS

Custom **Hornet (Hollow Knight: Silksong)** cursor set adapted for **macOS**.

## Requirements

To use these cursors, you need the **Mousecape** application:

- **Mousecape by Alex Zielenski**  
  GitHub: https://github.com/alexzielenski/Mousecape

For **macOS Tahoe** users, please use this compatible pre-release fork:

- **Mousecape Tahoe Support (Pre-Release) by Adam Wawrzynkowski**  
  https://github.com/AdamWawrzynkowskiGF/Mousecape-TahoeSupport/releases/tag/PreRelease-v01

The original cursor artwork was created by **Coldyhands** and adapted here for macOS.

## Installation Guide

1. Open **Mousecape**.
2. Import the `.cape` file.
3. Apply the cursor set.
4. Enjoy your new Hornet-themed cursor!
